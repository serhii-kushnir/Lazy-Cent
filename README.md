# Lazy Cent

**Lazy Cent** — це безкоштовний веб-застосунок для ведення бюджету, створений для того, щоб зробити контроль над фінансами максимально простим та швидким[reference:0]. Сервіс допомагає приватним особам, парам та сім'ям відстежувати витрати, планувати місячний бюджет і досягати фінансових цілей без зайвої складності та реклами.

> **Гасло:** «Кожна копійка під контролем»[reference:1]

---

## 🚀 Основні можливості

| Функція | Опис |
| :--- | :--- |
| **Місячний бюджет** | Встановлення лімітів за категоріями, прогноз витрат на кінець місяця та індикатор використання бюджету в реальному часі[reference:2]. |
| **Наочна аналітика** | Кругові діаграми, стовпчики по днях та детальна статистика по кожній категорії[reference:3]. |
| **Історія за днями** | Кожен день має окрему сторінку з усіма транзакціями, фільтрами та пошуком[reference:4]. |
| **Гнучкі категорії** | Можливість створювати власні категорії, редагувати їх та встановлювати індивідуальні ліміти[reference:5]. |
| **Нотатки** | Швидкі нотатки з кольорами, закріпленням і архівом (аналогічно Google Keep, але поруч із бюджетом)[reference:6]. |
| **Безпека та приватність** | Шифрування паролів (BCrypt), вхід через Google, повний контроль над даними. Жодної реклами[reference:7]. |
| **Доступ з будь-якого пристрою** | Застосунок працює у браузері (PWA), усі зміни синхронізуються автоматично[reference:8]. |
| **Безкоштовно назавжди** | Без обмежень за кількістю транзакцій, категорій чи нотаток. Жодних прихованих платежів[reference:9]. |

---

## 🛠️ Як це працює

Система побудована навколо **щоденного обліку**. Кожен день — це окремий запис із транзакціями. Lazy Cent автоматично:

- розраховує баланс на кінець дня;
- переносить залишок на наступний день;
- формує аналітику за весь місяць[reference:10].

## 🏁 Швидкий старт

1. **Зареєструйтеся** за 30 секунд (без кредитної картки).
2. **Додайте** свою першу витрату або дохід.
3. **Встановіть** місячний ліміт для категорії.
4. **Слідкуйте** за аналітикою та заощаджуйте![reference:11]

> Детальніше на офіційному сайті: [https://lazycent.com/](https://lazycent.com/)

## 🧰 Технологічний стек

- **Backend:** Java 17, Spring Boot 3.2, Spring Security, Spring Data JPA, Flyway, H2 Database
- **Frontend:** Thymeleaf, Bootstrap 5, Chart.js, JavaScript
- **Інше:** Maven, Lombok, Caffeine Cache, JavaMail, Apache POI, JaCoCo (покриття тестами)
